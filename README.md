# fitness-widget
Purpose 

Our team will develop a fitness widget that helps users figure out a consistent full workout plan that they can set and update as they perform their exercise routine. This application will use the gymfit API to fetch exercises, their details, their muscle heatmap, and alternative exercises. Furthermore, our application will provide users with the ability to filter exercises and log their workouts. 

Features: 

* Filtering Exercises 
  * Upper body, lower body, chest, back 
  * Equipment (weights, bands, mats, etc) vs No Equipment 
  * Dynamic (pre-workout) and Static (post-workout) stretches 

 

Potential Additional Features:

* Favourite workouts 
* Creating personal workout plan 
* Logging workout reps and sets 
* Tracking workout history details (calories burnt, consistency, rest days, etc.)
